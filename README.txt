DJRT WINDOWS DESKTOP APP

This package contains your DJRT invoice app inside a Windows desktop shell.
The original calculation logic and invoice design are preserved in index.html.

TO BUILD ON A WINDOWS PC:
1. Install Node.js LTS from https://nodejs.org/ (choose the Windows Installer).
2. Extract this ZIP into a normal folder.
3. Double-click BUILD_WINDOWS.bat.
4. Wait for npm to download the build tools and create the app.
5. Your installer and portable EXE will be in the dist folder.

IMPORTANT:
- This ZIP is the Windows app source/build package, not a compiled EXE.
- Building requires Windows and an internet connection for the first setup.
- After installation, the DJRT app itself works locally/offline; printing uses the Windows print dialog.
